# Todo管理アプリ

## 概要

Laravelを使用して作成したTodo管理アプリです。

Todoの登録・編集・削除・完了状態の変更に加えて、
検索・絞り込み・期限・優先度・並び替えなどの機能を実装しています。

## 使用技術

- PHP
- Laravel
- MySQL
- Bootstrap
- Vite

## 主な機能

- ユーザー登録・ログイン
- Todoの追加
- Todoの編集
- Todoの削除
- Todoの完了・未完了切り替え
- Todoのキーワード検索
- 完了・未完了による絞り込み
- Todoの期限設定
- Todoの優先度設定
- 期限・優先度による並び替え
- ユーザーごとのTodo管理

## 工夫した点

- 検索条件を維持したままタスクの操作を行えるようにした
- URLを直接書き換えても不正アクセスができないようにした
